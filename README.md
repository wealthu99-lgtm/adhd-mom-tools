# ADHD Mom Tools – Free Web App

Three calm, ADHD-friendly tools in one free website:

1. **Focus Timer** – Gentle, customizable timer for time blindness
2. **Brain Dump Unloader** – Turn mental chaos into clear tiny steps
3. **Visual Routine Builder** – Build simple daily/weekly visual schedules

## How to Deploy on Netlify (2 minutes)

1. Go to [netlify.com](https://www.netlify.com) and log in (or sign up free)
2. Drag and drop the entire `adhd-mom-tools` folder onto the Netlify dashboard
   **OR**
   - New site → Import from Git (if you put it on GitHub/GitLab)
3. Netlify will automatically publish it
4. Your site will get a free URL like `random-name.netlify.app`
5. (Optional) Add your own custom domain later
